# QR Code Generator — Streamlit

A modern and customizable QR Code Generator built with **Python, Streamlit, HTML, CSS, and JavaScript**.

Create QR codes for different types of content and customize their appearance with colours, dot styles, and custom logos.

---

## 🚀 Features

- 🔗 Generate QR codes for URLs
- 💬 Generate WhatsApp QR codes
- 📝 Generate QR codes for text
- 🎨 Customize foreground and background colours
- 🔘 Customize QR dot styles
- 🖼️ Upload a custom logo
- 👀 Preview generated QR codes
- ⬇️ Download QR codes
- 📋 Copy generated QR images
- 🕘 QR generation history
- 🌓 Light and dark theme
- 📱 Responsive interface

---

## 🛠️ Tech Stack

| Technology | Usage |
|------------|-------|
| Python | Application logic |
| Streamlit | Web application framework |
| HTML | Interface structure |
| CSS | Styling and responsive design |
| JavaScript | Frontend interactions |
| qrcode | QR code generation |
| Pillow | Image processing and logo handling |
